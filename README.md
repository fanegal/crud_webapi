# crud_webapi — demo_truehome

A CRUD Web API demo in C# / ASP.NET, built with a layered architecture.

## Structure
- `entidades` — domain entities
- `data_access` — data access layer
- `Business` — business logic
- `crud_webapi` — API project

## Stack
C# · ASP.NET Web API

## How to run
1. Open `crud_webapi.sln` in Visual Studio.
2. Restore NuGet packages.
3. Configure the database connection string.
4. Run the API project.
